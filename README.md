# GTA 산안드레아스 · PS2 한글 패치

**Grand Theft Auto: San Andreas (PlayStation 2, NTSC-J / SLPM-65984) 한글 패치.**
일본판을 기반으로 대사·메뉴·자막을 한글화하고, 폰트를 전면 교체했으며, 북미판 수위의 검열 해제를 포함합니다.

> **자료 유실이 우려되어 이번 v0.970부터 GitHub에 등록을 시작합니다.**
> 이전 판본(v0.900 · v0.969 등)은 완성도 낮은 **로스트 미디어**로 취급해 주시기 바랍니다. 😄

최신 배포는 [**Releases**](../../releases) 에서 받으세요. 버그 제보는 [**Issues**](../../issues) 로 부탁드립니다.

---

## 이 패치가 하는 일

- **대사·메뉴·자막 한글화** — 미션 대사, 상점·도장·도박장 UI, 조작 안내 등.
- **폰트 전면 교체** — 영문·숫자·기호를 한글과 같은 서체(사천항공체)로 다시 그려, 한글 옆에서 겉돌던 원판 라틴 폰트를 대체. 자막에서 글자가 겹치거나 점이 튀던 것도 제거.
- **자막 줄바꿈 교정** — 어절이 중간에서 뚝 끊기던 것을, 게임의 컷신/필드 글자수 한도에 맞춰 어절 단위로 다시 정렬.
- **일본판 검열 해제** — 원판이 잘라낸 폭력 연출을 북미판 수위로 복원(쓰러진 적 밟기, 신체 절단, 피격 시 화염·비명, 사망 시 소지금 드롭, 경찰 과잉 진압).
- **핫커피(성인 콘텐츠) 정상 작동** — 이전 판본에서 재생되지 않거나 투명한 벽에 갇히던 문제를 해결. **별도 선택 패치**로 분리했습니다.
- **원본과 동일한 게임 CRC 유지** — 기존 치트·세이브가 그대로 호환됩니다.

지명·미션명·차량명은 영문 원문 그대로 두었습니다(한글로 바꾸면 빅폰트가 안 붙거나 세이브의 미션명이 깨집니다). 일시정지 메뉴 탭(System, Controls 등)도 게임이 그 폭에 맞춰 레이아웃을 잡아 영문 유지입니다.

## 적용 방법

이 패치는 **NTSC-J 일본판 ISO 하나에만** 적용됩니다. ROM은 배포하지 않습니다.

| | |
| --- | --- |
| 파일명 | `Grand Theft Auto San Andreas (NTSC-J).iso` |
| 크기 | 4,495,507,456 바이트 |
| MD5 | `aa7cdf78c953f898443dbb5f89c3187f` |
| SHA-1 | `5dfb598053c4dbc1c87c407fc70fbeef6582bb76` |

**1단계 — 한글 패치 적용 (필수)**

```
xdelta3 -d -s "Grand Theft Auto San Andreas (NTSC-J).iso" GTA_SA_KR_v0.970_FULL.xdelta "GTA SA 한글 v0.970.iso"
```

**2단계 — 핫커피(성인 콘텐츠) 복원 (선택)**

1단계 결과 ISO에 이어서 적용합니다.

```
xdelta3 -d -s "GTA SA 한글 v0.970.iso" GTA_SA_KR_v0.970_hotcoffee.xdelta "GTA SA 한글 v0.970 핫커피.iso"
```

GUI가 편하면 [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher), 명령줄은 [xdelta3 공식 배포판](https://github.com/jmacd/xdelta-gpl/releases)을 쓰세요. (Source에 기준 ISO, Patch에 xdelta 파일)

## 이전 세이브 이어 쓰기

검열판이나 이전 버전에서 만든 세이브를 이 패치로 이어 쓰면, **의상점 데이트가 진입 시 멈추는** 문제가 있습니다(세이브에 박힌 플래그가 원인). 이럴 때만 아래 도구로 세이브를 한 번 고쳐 주세요. **새로 시작한 게임에는 필요 없습니다.**

- `tools/gtasa_save_fix.html` — 브라우저에서 열어 `Mcd001.ps2`를 끌어다 놓으면 고친 파일을 내려받습니다. 설치 불필요, 파일은 PC 밖으로 나가지 않습니다.
- `tools/gtasa_save_fix.py` — 명령줄: `python gtasa_save_fix.py Mcd001.ps2` (원본은 `.bak`으로 자동 백업)

PCSX2 메모리카드(`Mcd001.ps2`)와 폴더식 메모리카드의 세이브 파일(`*.b`) 모두 지원합니다.

## 곁들이면 좋은 것 (PCSX2 치트)

PCSX2는 아래 부가 기능을 전부 "치트(cheats)"로 취급합니다. `.pnach` 파일을 `PCSX2\cheats\` 에 넣고, 게임 속성 → Cheats → Enable Cheats 를 켠 뒤 목록에서 고르세요. 한글 패치가 CRC를 원본과 동일하게 맞춰놨기 때문에 그대로 먹습니다.

- **화면 개선** `SLPM-65984_60FE139C_와이드픽스.pnach` — 와이드스크린 16:9, 레이더 원형 보정, 고스팅 제거, 60 FPS, 항공기 계기 정렬
- **조작 편의** `SLPM-65984_60FE139C_치트.pnach` — 무적, 무한 체력/아머/탄약/스프린트, 수배 0, 돈, 근육/스태미너 등 17종
